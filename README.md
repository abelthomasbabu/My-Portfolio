# Portfolio Website

Personal site of Abel Thomas Babu: AI engineer working on LLMs and RAG, on a Python backend foundation. All copy lives in `src/data/content.js`.

## Run Locally

Clone the project

### Prerequisites

* [Node.js](https://nodejs.org/)
* [Git](https://git-scm.com/)

### Clone and Run

```bash
git clone https://github.com/abelthomasbabu/My-Portfolio.git
cd My-Portfolio
npm install
npm run dev
```

Your app will be available at: [http://localhost:5173](http://localhost:5173)

---

## Commands

```bash
npm test        # content and component tests (Vitest)
npm run lint
npm run build
```

## Tech Stack

* **React** + **Vite**
* **Tailwind CSS** v4
* **Geist** and **Geist Mono** fonts
* **Lucide** icons
* **Vitest** + Testing Library
* **Vercel** for deployment
